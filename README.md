# vli-preview

Repositório **público**, usado exclusivamente para hospedar via GitHub Pages
entregáveis visuais finais (landing pages, protótipos) para visualização
rápida por qualquer pessoa com o link.

> **Este repositório é público.** Só devem entrar aqui arquivos finais,
> estáticos e já revisados. **Nunca** subir dados internos, auditorias,
> planilhas, credenciais, scripts de build ou qualquer material de
> trabalho/rascunho — esse tipo de conteúdo fica no repositório privado
> `VLI-Logistica`.

## Estrutura

- `index.html` — galeria/índice com link para cada projeto
- `<nome-do-projeto>/index.html` — uma pasta por projeto, cada uma com seu
  entregável final autocontido

## Publicar

1. Ative o GitHub Pages em **Settings → Pages → Source: Deploy from a
   branch → `main` / `(root)`** (uma única vez)
2. A cada novo entregável: crie a pasta do projeto, adicione o link no
   `index.html` da raiz, commit e push — o Pages atualiza sozinho em 1–2
   minutos
